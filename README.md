# secaware-infra

Containers, CI and deployment for SecAware, a free platform for short cybersecurity-awareness courses. The app runs as containers on [Dokploy](https://dokploy.com).

This repo is a training project. It has no services yet: the issues add them.

## Check it

You need Docker with Compose.

```sh
docker compose config
```

You should see the project name and an empty services list.
